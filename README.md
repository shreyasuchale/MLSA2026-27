📚 Flashcard Study App

A fully-featured, vanilla JavaScript flashcard study application with flip animations, score tracking, and persistent storage.

Features

Core Features

✅ Create Flashcards - Add questions and answers dynamically

✅ Flip Animation - Smooth 3D flip effect to reveal answers

✅ Navigation - Move between cards with Previous/Next buttons

✅ Category Support - Organize cards by subject/category

Advanced Features

✅ Shuffle - Randomize card order for varied study sessions

✅ Score Tracking - Track correct/incorrect answers

✅ Known/Unknown - Mark cards as known or unknown for progress monitoring

✅ Category Filtering - Filter and study by specific categories

✅ Local Storage - Automatically save and load all data

✅ Responsive Design - Works on mobile, tablet, and desktop

✅ Keyboard Shortcuts - Efficient navigation and interactions


How to Use

Getting Started

Open index.html in a web browser

Fill in the "Add Flashcard" form with a question and answer

Optionally add a category (defaults to "Uncategorized")

Click "Add Card" to create the flashcard


Studying

View the flashcard with the question displayed

Click the card or press Space to flip and reveal the answer

Use → (Next) or ← (Previous) to navigate between cards

Mark your answers:

Click ✓ Known or press Enter if you got it right

Click ❌ Unknown or press Backspace if you need more practice


Additional Features

Shuffle - Randomize card order for varied study sessions

Filter - Click a category in the sidebar to study only those cards

Reset Score - Clear your score while keeping flashcards

Clear All - Delete all flashcards and reset (with confirmation)
